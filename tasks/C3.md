# C3: Microsimulation

- Owner: Codex builds, Claude reviews
- Depends on: A3, C2
- Output: `src/micro.py`

## What to do
Apply spending and tax changes to household incomes/benefits; output Gini, poverty, top 1%/10% shares. Validate against Higgins & Pereira (2013) and Neri et al. (2018).

## Rules
- One branch per task (`task/c3`), small PR with tests where code is involved.
- Never invent, interpolate or fill missing values without a source; keep value + year.
- Record every source (URL, date, licence) in `data/raw/SOURCES.md`.
- Mark proxies as proxies.
