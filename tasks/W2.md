## 1. Education channels (from `src/education.py`, `config/ed_proposed.yaml`, `docs/education_review.md`)
- C5 already contains the schooling channel (`schooling_log_output_effect`). Do **not** add ED's schooling channel
  again. Add only ED's **capacity** channel (higher-education + IF capacity -> GDP level) and **innovation** channel
  (public R&D stock -> GDP level), as two new C5 channels in `src/feedback.py` (`education_capacity`,
  `innovation_capacity`), with contributions reported like the others (`*_contribution_pct`), included in
  `gdp_level_vs_s0_pct_with_feedback` and therefore in the feedback debt path.
- Inputs per scenario-year: that scenario's education and R&D spending change vs S0 from its packages, computed with
  the same functions ED uses (`programme_spending_changes` / package paths; for S1-S5 their package gaps). S0 = 0.
- Parameters drawn per draw (Monte Carlo stream `[seed, 6]`, new, so existing streams are unchanged): capacity
  elasticity uniform(0, 0.04) per log capacity (15-year phase-in), innovation elasticity uniform(0, 0.02) per log
  R&D stock (perpetual inventory, 15% depreciation). Same draw for every scenario.
- Sensitivities via CLI `--education-sensitivity {none,half_record,record_repeat,lula_half_recomposition,
  lula_record_recomposition}` (default `none`): applies the ED sensitivity definitions in `config/ed_proposed.yaml` to
  the matching programme scenarios only; recorded in metadata. No effect on S0-S5.
- New outputs (MACRO or SOCIAL as fits): `education_capacity_contribution_pct`, `innovation_capacity_contribution_pct`,
  `employer_share_change_pp` (ED composition channel, indicator only), `youth_homicide_rate_change_per_100k`
  (indicator only).

## 2. Firm-distress indicators (from `config/bk_proposed.yaml`)
- Scenario real-rate deviation vs S0 in each year = (scenario C5 risk premium - S0 C5 risk premium), in pp (plus the
  I1 offset difference, which is zero across scenarios). Expose the premium per scenario-year from `src/feedback.py`
  if not already available.
- `firm_npl_change_vs_s0_pp` = coefficient x deviation, coefficient drawn per draw from normal(0.460, se) with se =
  (0.664 - 0.256)/3.92, stream `[seed, 7]`.
- `firm_exit_rate_change_vs_s0_pp` = coefficient x deviation, coefficient drawn from normal(0.713, (1.512 +
  0.085)/3.92). Label as imprecise (CI includes zero) in units/metadata.
- Indicators only: no feedback to GDP (state this in metadata and docs).
