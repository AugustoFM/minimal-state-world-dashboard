# W1 - Wire the I1 real-rate path (sensitivity only) and the E3 poverty indicators into the Monte Carlo

Owner: Codex (implementation, tests), Claude (review, runs). User decision 2026-10-21: the I1 rate path is a
**sensitivity only**; S0 and every default run keep the fixed historical real rate (5.05% central, triangular range).
Default outputs must be bit-identical to the current code when the new option is off (check: the existing test suite
plus a 3-draw `python -m src.montecarlo --draws 3` summary compared before/after).

## 1. Real-rate path option (off by default)
- Source: `config/i1_proposed.yaml`, key `s0_path_before_fiscal_term`, field `difference_from_fixed_5_05_pp` per year
  2026-2045. Define the **offset** for year y as that difference (pp); offset = 0 for the base year 2025 and earlier;
  after the last year hold the last value. Read it, do not modify the file.
- Applied as: real rate in year y = the draw's (or corner's) `effective_real_interest_rate` + offset(y). The MC
  uncertainty around the rate is kept; only the time profile changes. Identical for every scenario (S0, S1-S5, P
  programmes): it is a baseline assumption, not a scenario effect.
- Mechanism: one helper in `src/macro.py`, e.g. `real_interest_rate_for_year(inputs, variant, year)` that returns
  `macro_input(inputs, "effective_real_interest_rate", variant) + offset(year)` where the offsets live in
  `inputs["derived"]["real_rate_path_offset_pp"]` (dict year -> pp; absent or empty = 0, the default). Use it at every
  place the scalar is used today, each in its own debt recursion, so the year index is the year being stepped:
  `src/macro.py` `run_corner`, `src/programs.py` `s0_path` (programme sizing on the S0 path), `src/external.py`
  `apply_external`, `src/feedback.py` (`_evaluate` / `apply_feedback`: accept an optional per-year offset mapping,
  default None = current behaviour). The C5 risk premium stays added on top as today.
- `src/montecarlo.py`: CLI flag `--rate-path i1` (default none). When set, load the offsets into the context inputs
  before the draws; record in `run_metadata.json` ("real_rate_path": "i1_proposed_offsets", the offsets, source file
  and its sha256). Without the flag nothing changes.
- Tests (`tests/test_macro.py`, `tests/test_montecarlo.py`, `tests/test_feedback.py`, `tests/test_programs.py`,
  `tests/test_external.py` as needed): zero offsets reproduce the scalar path exactly; a constant offset of +1 pp equals
  raising the scalar by 1 pp; a year-varying offset enters the year being stepped (hand-computed 3-year debt recursion);
  the offset is identical across scenarios so S0-paired differences change only through r-g (assert all scenarios
  receive the same rate in a given year).
